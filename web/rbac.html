RBAC Control

Manage AzerothCore account permissions, default roles, inherited permissions, and inspect every command available on each realm.

Administrator access required

RBAC management is restricted to GM level 3.

Account permissions

Explicit grants and denies override the selected account’s default security role. “All realms” uses realm ID -1.

Default permissions

Permissions inherited by every account at a security level. Choose “All realms” or the selected realm.

Permission inheritance

Linked permissions form roles. Links are shared by all realms and are intentionally separate from account grants.

RBAC permission catalogue

Core and module permission IDs available in rbac_permissions. These definitions are normally supplied by AzerothCore updates.

World commands

Commands come from the selected realm’s command table. Security is the command’s minimum GM level; RBAC permissions are listed separately above.
